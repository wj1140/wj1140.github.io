# 健身知识百科网页

这是一个全面介绍健身知识的静态网页，包含了健身的基础知识、营养指导、运动类型、训练计划和实用建议等内容。

## 文件结构

- `fitness-knowledge.html` - 主页面文件
- `style.css` - 样式文件
- `script.js` - JavaScript交互功能
- `README.md` - 说明文档

## 功能特性

### 页面内容
- 健身简介及好处
- 详细营养知识（宏量与微量营养素）
- 各类运动类型介绍
- 初学者和进阶者训练计划
- 实用健身建议
- 个性化健身计划生成（新增）
- 个性化饮食计划生成（新增）

### 交互功能
- 平滑滚动导航
- 滚动时自动高亮导航项
- 淡入动画效果
- 返回顶部按钮
- 响应式设计（适配移动设备）
- 个性化健身计划生成器（新增）
- 个性化饮食计划生成器（新增）

### 个性化计划功能（新增）
- 根据年龄、性别、身高、体重生成
- 目标体重设置
- 活动水平评估
- 健身目标选择（减脂、增肌、维持、综合健身）
- 个人化营养建议
- 定制化训练计划
- 详细的每日饮食安排（早餐、上午加餐、午餐、下午加餐、晚餐、晚间加餐）
- 时间预期计算

### 技术特点
- 现代CSS布局（Grid + Flexbox）
- 响应式设计
- 交互动画
- 性能优化

## 使用方法

1. 将所有文件保存在同一目录下
2. 用浏览器打开 `fitness-knowledge.html`
3. 在"个性化健身计划"部分输入您的身体数据
4. 点击"生成我的健身计划"获取个人化建议
5. 点击"生成我的饮食计划"获取详细饮食安排
6. 通过导航栏访问"饮食计划"页面查看每日饮食详情
7. 浏览其他章节获取更多健身知识
